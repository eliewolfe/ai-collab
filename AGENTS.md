# Agent instructions

1. Start by reading `README.md`, your user's `users/<name>/README.md`, and
   `users/<name>/inbox/`.
2. For background, read `knowledge/synthesis/`. Only open `knowledge/ai-notes/` when a
   synthesis file links to it or you need detail.
3. Put intermediate notes and handoff context (everything a new session needs) in
   `knowledge/ai-notes/`, and link them from the relevant synthesis file.
4. Convert any new file in `knowledge/raw-sources/` to markdown in
   `knowledge/ai-notes/`, noting the source path at the top.
5. Work inside your user's folder; write to others only via their `inbox/`.
6. Update headline results in the relevant README when findings change.
