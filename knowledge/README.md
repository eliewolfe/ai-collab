# Knowledge base

- `synthesis/` – summaries/syntheses for humans and agents. Read by default. Link to
  `ai-notes/` files for detail.
- `ai-notes/` – AI intermediate notes, including markdown conversions of raw sources
  and handoff context. Not read by default; reached via links from synthesis files.
- `raw-sources/` – original manuscripts (PDF), audio, etc. Each should have a
  markdown conversion in `ai-notes/`.
